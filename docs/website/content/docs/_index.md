Short pages, one topic each, for people learning pastor. New here? Start
with [install](start/install/) and [first run](start/first-run/). The
[concepts](concepts/) explain each part, [deployment modes](deploy/) show
how to set it up, and the [examples](examples/) are real workflows to copy.

**Then pick what you came for.** Each page does one thing from start to end:
[another machine](deploy/flock/) to share the load,
[a PR fix round](examples/pr-fix-round/) from one command,
[urgent work first](examples/urgent-first/) with priorities and the queue,
[a job every morning](examples/morning-job/) on a schedule,
[board cards](examples/board-cards/) that become branches, and
[a sandbox](examples/sandbox/) for untrusted work.
