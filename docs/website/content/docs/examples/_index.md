Workflows from everyday use, with the names swapped for placeholders: `desk` is the head, `server-1` and `laptop` take tasks, `~/notes` is a notes vault and `~/src/app` the repo the agents work on.

Each page is one workflow the maintainer runs every day. It says what the
workflow is for and what it needs, gives the config and commands to copy as
they are, and shows what you see when it runs. Swap in your own machines,
paths and repo, and each ends with links to the concepts behind it.
