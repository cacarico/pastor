what

pastor runs coding agents (Claude Code, opencode, Codex) on machines I own: a home server, a Raspberry Pi, a spare laptop.

I hand it a task or a schedule and close my laptop. Later I check what got done, and which agent stopped to ask me something.

install

$ curl -fsSL https://raw.githubusercontent.com/cacarico/pastor/main/install.sh | sh

One binary in ~/.local/bin. Each machine needs herdr 0.9+, and the head needs ssh to the others. more

how

  1. You give it work: one task, or a job that finds work on a schedule.
  2. It picks a free machine and starts the agent in a herdr terminal there.
  3. It watches the agent: running, blocked on a question, or done.
  4. You read the output, answer the question, or attach and take over.

first run

# add a machine, keep the head running
$ pastor machine add pi-1 user@pi-1
$ pastor setup systemd

# give it a task, in its own git worktree
$ pastor task run "Fix the flaky test in ci.yml" --repo '~/work/api' --worktree

# later: see where things are
$ pastor task list

# t-1 is blocked: the agent asked something
$ pastor task read t-1
$ pastor task send t-1 "yes, go ahead"
$

what it is not

  • a platform. Built for my own workflow first. Ideas are welcome when they fit.
  • a cloud service. Everything runs on your machines, over ssh.
  • a chat app. Every agent is a real terminal you can attach to.
  • stable. It is young. Compatibility is best effort.

how I use it

  • a Kanban board. A job reads my notes' board every minute; a card tagged #agent becomes a task on its own branch, and the card moves to In Review when the agent is done.
  • a PR fix round. pastor task run "Address the review on #42" --repo '~/src/app' --worktree --model sonnet, then task read when it stops.
  • another machine. pastor machine add server-1 user@server-1 --max-agents 3: its tasks share the load with the head, over ssh.
