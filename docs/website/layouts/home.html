pastor

An agent orchestrator for a flock of machines.

Queue tasks, schedule jobs, and let pastor spread coding agents (Claude Code, Codex, opencode) across your flock over ssh.

  • queue tasks wait their turn, by priority
  • jobs cron or a board turns into tasks
  • flocks any box you can ssh to runs agents

Every agent is a real terminal you can attach to. You check back later: done, stuck, or waiting on you.

install

$ curl -fsSL https://cacari.co/pastor/install.sh | sh

One binary in ~/.local/bin. Each machine needs herdr 0.9+, and the head needs ssh to the others. more

what you can do

  • run agents on another machine: add a box over ssh, and it shares the load.
  • fix a PR with one command: an agent in its own worktree, on the model you name.
  • put urgent work first: priorities, a queue you can reorder, low work paused for urgent.
  • run a job every morning: a schedule that turns into tasks on its own.
  • hand board cards to agents: tag a card, and it becomes a branch.
  • keep untrusted work in a sandbox: outside PRs and issues run on a machine with nothing to steal.

why it exists

I built pastor to learn how AI agents, their harnesses and AI governance work in practice, and to hand my own daily tasks and processes to agents.

It is shaped by that use first. why I built it

what it is not

  • a platform. Built for my own workflow first. Ideas are welcome when they fit.
  • a cloud service. Everything runs on your machines, over ssh.
  • a chat app. Every agent is a real terminal you can attach to.
  • stable. It is young. Compatibility is best effort.
