### Added

- `pastor workdir place` places sets for agy: skills in `.agents/skills/`,
  named hooks merged into `.agents/hooks.json`, and instructions as a block
  in `AGENTS.md`, or as a rule of the set's own in `.agents/rules/` when the
  repository tracks `AGENTS.md`. Rules and custom agents go as plain files.
  A set with hooks for a folder agy does not trust gets a row saying so.
